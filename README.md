# I used

### os 
* Built-in library for interacting with the operating system (though unused or part of boilerplate here).

### random 
* Built-in library for generating pseudo-random numbers.

### sys
 * Built-in library for accessing system-specific parameters and functions (used here to check if the script is frozen via PyInstaller).

### time 
* Built-in library for time-related functions.

### pathlib  
* Built-in library for object-oriented filesystem paths (used for handling resource_folder and save_folder paths).

### turtle 
* Built-in graphics library commonly used for introductory programming and simple vector drawing.

### pygame 
* External library for writing video games (attempted to be imported inside the try block).
